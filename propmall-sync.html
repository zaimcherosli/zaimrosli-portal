📱 Untuk Telefon Pintar (Android / iPhone)

Di telefon pintar, salin kod bookmarklet di bawah dan simpan sebagai Bookmark di Google Chrome atau Safari:

1
Tekan butang kuning "Salin Kod Bookmarklet" di atas.
2
Bookmark halaman ini di telefon anda (tekan ⭐ di Chrome atau Add Bookmark di Safari), dan namakannya ⚡ Sync ZaimRosli.
3
Tekan Edit Bookmark, padam URL lamanya dan Paste kod yang disalin tadi.
4
Cara Guna di Telefon: Bila buka listing di PropMall (Chrome), tekan pada ruangan URL atas ➔ taip perkataan sync ➔ tekan bookmark ⚡ Sync ZaimRosli. Tab baru Admin portal akan terbuka dan semua gambar HD terus sedia! ✨
